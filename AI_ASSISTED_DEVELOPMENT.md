# AI-assisted development

This modified Tincan fork was developed with extensive assistance from **ChatGPT by OpenAI**.

The repository owner defined the requirements, chose the product behavior, tested changes on Windows and Arch Linux, and reviewed what was accepted into the fork.

ChatGPT assisted with:
- Rust implementation and refactoring;
- protocol design and control-plane fixes;
- direct file-transfer implementation;
- PTT press/release and Linux global-input work;
- test coverage and regression debugging;
- build and release workflows;
- technical documentation.

This disclosure is included intentionally so users and contributors can clearly see that AI-assisted development was part of the engineering process.

The final project direction and acceptance decisions remain under human control.
